- New crate `fs-starter` (PROBE, branch `unreviewed/probe-fs-starter`, not released; trait-delta pilot 1, draft of Opus 2026-11-17): the program shell of every program as a library. `main_exit(&Parts)` / `run`: words (`--version`, `--help`, `serve`, `mcp --as ACTOR`, `--frontend`, `--socket`, `--fresh`, `--resumed`), the server gate (`ServerGate`, standard `SingleGate` over `ensure_single`), frontend manifests (AppStream `addon`, `XdgManifests`, user level before system level, user level always shown as `manifest-unchecked`), choice (word > person > standard), `precheck` and `--check`, fallback with a note, `StartHook` (before/after, for the update probation), exit codes 0/1/2/3 and the frontend's exit unchanged. Every failure is a `StarterCode` (13 codes, message key `starter-error-<name>`), never a sentence. The optional feature `conformance` (never in `default`) adds the suite `starter` (12 rules, 12 bench mutants) on top of `fs-conformance`.
- New dependency `roxmltree` 0.20 (licence: MIT OR Apache-2.0, no dependencies of its own; already in fs-packages-catalog). Probe pins: `fs-conformance` from fs-types main 339aa24 by `rev` (optional); the module `coded_stub` stands in for `fs_types::coded` and is replaced after the fs-types lift.

- New (additive): `keep_connected` with `Session`, `Resync`, `Reconnected { attempt, resync_needed }`, `ReconnectTimes`, `Backoff`, `ReconnectEnd`: after a lost connection, a restarted or replaced server (update, take-over) it connects again through the handshake (the program's `ServerStarter` may start the server), subscribes again, and tells the program that a full reload is needed; pauses 1 s, 2 s, then 5 s (the ceiling), every step has a limit, after `give_up` (30 s) `Resync::gave_up` and the loop ends. The comparison with the contract's `generation()` is the program's.
- New (additive, Unix): `Heartbeat` (own thread, `<socket>.beat`, 0600): `busy(what, progress)`, `idle`, `tick`, `on_save(SaveOnTerm)`, `save_now`; `ask_beat`, `ask_save`, `Pulse`, `Beat`, `Saved`, `Watch`, `HangTimes` (ping 2 s, no heartbeat 10 s, tick standing still 10 s, no progress 90 s), `Verdict`, `Hung`.
- Fixes after review: a heartbeat channel is proven (it answered during the watch and its `SO_PEERCRED` pid is the listener of the socket), not assumed from a file; ` (deleted)` is cut from the program path only if the file is really gone (link count 0); a tick that stood still counts as hanging only after a watch of `no_tick` (a long-running program that is silent for 2 s is not ended); `datadir::{Meta, Action, decide}` are Unix only (Windows clippy). The heartbeat comes from a thread of its own; 2 s is only the detection of a silent contract, ending needs the watch (10 s / 90 s) and a save attempt first.
- New (additive, Unix; ending Linux only): `ensure_single` with `SingleTimes`, `Single`, `TakenOver`, `SingleError`, `Stuck`, `decide_takeover` (rules generalised from fs-tasks 0.0.10: `SO_PEERCRED`, same user, program file by inode or real path, start time before and after `pidfd_open`, never pid <= 1 or itself, socket file removed only by inode). A hanging server of this program is saved (heartbeat `save`), ended (SIGTERM; SIGKILL only after the wait, with a heartbeat channel and no answer) and replaced; a `busy` server that moves is never ended; a program without a heartbeat channel gets NO signal at all (nothing could be saved first): only the report `no-control` ("please close it"); another program is only reported. `Heartbeat::tick()` is mandatory (its age counts from `start`). Windows: `ensure_single` exists as a stub (handshake only, a silent server is reported as `unsupported`).
- BREAKING (v0.0.3, one signature): `prepare_data_dir` answers `Result<PathBuf, DataDirError>` instead of `io::Result<PathBuf>`. `?` into an `io::Result` keeps working (`From<DataDirError> for io::Error`); a caller that names the type `io::Result` without `?` must convert. LIFT NOTE for fs-tasks, fs-people and every program that calls it. New codes `server-unresponsive` (`pid`, `why`, `exe`, `limit-ms`) and `server-busy` (`pid`, `what`, `progress`): 18 codes.
- Auf Deutsch: Neu: `keep_connected` (Wiederverbinden mit Voll-Reload-Hinweis, Pausen 1/2/5 s, Frist 30 s), `Heartbeat` (eigener Thread: lebendig oder beschaeftigt, Takt des Arbeits-Threads, Speichern vor dem Ende), `ensure_single` (haengende Instanz erkennen: kein Herzschlag 10 s, Takt steht 10 s, kein Fortschritt 90 s; nur eigenes Programm wird gerettet und beendet, SIGKILL nur mit Beleg und Kanal; ohne Herzschlag-Kanal KEIN Signal, nur Meldung "bitte schliessen"; `tick()` ist Pflicht; beschaeftigte nie; fremdes Programm nur melden). Neue Codes `server-unresponsive`, `server-busy` (18 Codes).

- Review fixes of the error codes (Opus, A1-A5): the exhaustiveness of `RpcErrorCode::ALL` is a unit test over a `match` without `_` (a variant missing from the list no longer compiles; `ALL` is generated from the same list as the enum); tests for `kind` of a failed replacement and `server` of a timeout; `capability` comes from the problem extension, not from `detail`; `kind` tokens come from a fixed table, not from the `Debug` text of `io::ErrorKind`; the migration note names `cause: Box<RestartCause>`.
- New (additive code, breaking for one signature): `prepare_data_dir` answers `Result<PathBuf, DataDirError>` instead of `io::Result` (`DataDirError` converts into `io::Error`, kind `PermissionDenied` when not private, so `?` keeps working). A folder of this user that is too open is corrected to the owner bits through its descriptor (up to v0.0.2 it was refused, which stopped a program whose window had made the folder with 0755); a symbolic link, a file, somebody else's folder or a folder below a directory others can swap is refused. New code `data-dir-not-private` with the parameter `cause` (`foreign-owner`, `mode`, `symlink`, `ancestor`, `not-directory`), new `DataDirError`, `DataDirCause`; `RpcError::from(&DataDirError)`; 17 codes now (`server-unresponsive` is the 17th, see below).
- Auf Deutsch: Review-Korrekturen der Fehler-Codes (A1-A5, siehe oben). `prepare_data_dir` liefert `Result<PathBuf, DataDirError>` (wandelt sich in `io::Error`); ein zu offener eigener Ordner wird auf die Besitzer-Rechte zurueckgenommen (nur Rechte weg, nie dazu), Link, Datei, fremder Ordner oder ein Ordner unter einem fuer andere beschreibbaren Verzeichnis wird abgelehnt: neuer Code `data-dir-not-private` mit Parameter `cause`.

- New (additive): error codes with typed parameters instead of English sentences (ADR 0057). `RpcErrorCode` (15 stable kebab-case codes, `as_str`, `message_key` = `rpc-error-<name>`, `ALL`), `Param` (text or number), `RpcError` (`code`, `message_key`, `params`, `param`, `with_text`, `with_number`, `is_retryable`; `Display` is a technical code text `rpc.error: no-server (socket=...)`, no sentence). `RpcError::from(&HandshakeError | &Fault | &Problem | &Failure | &io::Error | &capnp::Error)` and `RpcError::of(&capnp::Error)`. A program translates `message_key()` with `params()` through its MessageFormat 2 files; the template is `docs/errors.md`. The `Display` texts of the existing error types stay as an English fallback for logs; a window must not show them.
- Migration (breaking, for v0.0.3): `HandshakeError::CannotRestart` carries `cause: Box<RestartCause>` (typed, `#[non_exhaustive]`) instead of `reason: String`; `cause.to_string()` gives the former text. `Expected::other_program_reason` is deprecated. Call sites: only a `match` on `CannotRestart { reason, .. }` must change to `cause` (none in the fs-messages, fs-resources, fs-draw clients: they print `e.to_string()` of `HandshakeError`; they switch to `RpcError::from(&e)`).
- Auf Deutsch: Neu, additiv: Fehler-Codes mit typisierten Parametern statt englischer Saetze (ADR 0057): `RpcErrorCode` (15 stabile Codes), `Param`, `RpcError` (`message_key()` = `rpc-error-<name>`, `params()`), `From` fuer alle Fehlertypen und `capnp::Error`. Das Programm uebersetzt ueber MessageFormat 2; Vorlage `docs/errors.md`. Die `Display`-Texte der bisherigen Fehler bleiben als englischer Rueckfall fuer Logs, ein Fenster darf sie nicht zeigen.
